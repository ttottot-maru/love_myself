# 비판자와 거리두기 4주

머릿속 비판자의 목소리와 거리를 두는 4주 기록 훈련입니다. 휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있고, 한 번 연 뒤에는 인터넷이 없어도 열립니다.

## 1. GitHub에 올리기

1. GitHub에서 **New repository**를 누릅니다. 이름은 예를 들어 `geori` 로 하고 **Public**으로 만듭니다.
   - GitHub Pages를 무료로 쓰려면 Public이어야 합니다. 공개되는 건 앱의 코드뿐이고, 내가 쓴 기록은 휴대폰 안에만 있어서 공개되지 않습니다.
2. 만든 저장소에서 **Add file → Upload files**를 누르고, 이 폴더의 파일을 모두 끌어다 놓습니다.
   - `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, 그리고 아이콘 그림 4개(`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`)
   - 폴더 없이 모두 맨 위에 둡니다. 휴대폰에서도 한 번에 고를 수 있습니다.
3. **Commit changes**를 누릅니다.

## 2. GitHub Pages 켜기

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 위쪽에 주소가 나옵니다. 예: `https://내아이디.github.io/geori/`

## 3. 휴대폰 홈 화면에 설치

**아이폰 (Safari로 열어야 합니다)**
1. 위 주소를 Safari로 엽니다.
2. 아래쪽 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
3. **홈 화면에 추가**를 누릅니다.

**안드로이드 (Chrome)**
1. 위 주소를 Chrome으로 엽니다.
2. 오른쪽 위 ⋮ 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.

설치한 뒤에는 홈 화면 아이콘으로 열어 주세요. 브라우저에서 연 것과 홈 화면 앱은 기록이 따로 저장될 수 있습니다.

## 홈 화면 아이콘이 안 나올 때

1. 브라우저에서 `https://내아이디.github.io/저장소이름/apple-touch-icon.png` 를 열어 봅니다. 그림이 안 나오면 아이콘 파일이 저장소 맨 위에 올라가지 않은 것입니다. 다시 올려 주세요.
2. 그림이 잘 나오는데도 아이콘이 비어 있다면, 휴대폰이 예전 상태를 기억하고 있는 것입니다. 앱에서 **백업 파일 저장**을 먼저 한 뒤, 홈 화면의 앱을 지우고 다시 '홈 화면에 추가'를 해 주세요. 그다음 **백업 불러오기**로 기록을 되돌립니다.

## 기록은 어디에 저장되나요

- 기록은 **이 휴대폰 안에만** 저장되고, GitHub나 다른 서버로 전송되지 않습니다.
- 그래서 다른 기기와 자동으로 이어지지 않고, 앱을 지우거나 브라우저 데이터를 지우면 기록도 함께 사라집니다.
- 앱 아래쪽 **백업과 복원**에서 일주일에 한 번 백업 파일을 받아두세요. 기기를 바꿀 때도 이 파일로 옮깁니다.

## 앱을 고쳐서 다시 올릴 때

`index.html`을 고쳐 다시 올린 뒤, `sw.js` 맨 위의 `VERSION = "v1"`을 `"v2"`처럼 하나 올려 주세요. 그래야 이미 설치된 휴대폰에서도 새 버전으로 바뀝니다. 바뀐 버전은 앱을 한 번 닫았다 다시 열면 적용됩니다.
